# Planejamento do jogo — Number Stiker

## Conceito
Jogo educacional 2D em linguagem C, com Allegro 5. Meteoros avançam em direção a uma cidade. Para destruir cada meteoro, o jogador precisa resolver corretamente uma operação matemática antes que ele atinja os prédios.

## Regras previstas
1. Um meteoro aparece com uma conta matemática.
2. O jogador digita a resposta e pressiona Enter.
3. Se estiver correta, o meteoro é destruído e o jogador ganha pontos.
4. Se estiver incorreta, o meteoro continua avançando.
5. Ao atingir a cidade, o jogador perde uma vida.
6. O jogo termina quando as vidas chegam a zero.
